# Weather Forecast Application

A sleek, responsive *Weather Dashboard* built using *React* and *Material-UI* that fetches and processes real-time climate data. The user interface features a dynamic background engine that changes visual themes instantly based on hot, cold, or rainy atmospheric conditions.

👉 *[View the Live Deployment](https://alina487.github.io/Weather-Forecast-App/)*

---

## 🚀 Key Features

* *Real-Time Data Integration* – Fetches up-to-the-minute atmospheric metrics using the OpenWeatherMap API.
* *Dynamic Environment UI* – Automatically switches styling configurations to match current local weather states.
* *Resilient Error State Management* – Features automatic state-clearing mechanics to gracefully transition between invalid location prompts and subsequent search inputs.

---

## 🛠️ Tech Stack & Dependencies

* *Frontend Framework:* React (Vite-optimized setup)
* *Styling & UI Library:* Material-UI (MUI Components & Icons)
* *Data Layer:* Fetch API / Async-Await structures

---

## 💻 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Alina487/Weather-Forecast-App
   ```
2. Navigate to the project directory:
   ```bash
   cd Weather-Forecast-App
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
